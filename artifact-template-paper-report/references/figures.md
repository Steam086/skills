# 论文配图：结构、裁剪与可读性

用于复合图、比例不适配、裁剪修复或需要精读的实验图。普通单图不必增加图组元数据或切换版式。

## 先确定阅读单位

区分论文的图编号、语义子图组、组内绘图区和 PDF 存储对象。它们不一定一一对应。结合全文页、子图编号、图注、图例和正文引用识别；PDF 的 Form/Image 对象只能提供定位线索。一个 Form 可能包含多组图，也可能重复使用；一组图可能由多个对象及页面文字共同组成。扫描页和直接绘制的矢量路径不一定有可独立提取的图对象。

同级 `paper-to-report/scripts/paper_pdf.py objects` 可列出指定页的对象类型、资源路径及局部边界；局部 BBox 不含页面变换，不可直接作为裁剪坐标。始终查看完整页面，特别检查对象外的子图编号、共享图例、脚注和单位。

可独立展示的裁片必须保留支持当前结论的比较条件。若多个子图依赖共享坐标轴、共享图例或跨图连线，先保留整体，或在每个新页面完整带上共享信息；不能按白色间隙机械分割。重排只改变展示顺序，父图/子图标识、颜色语义、尺度、数据与限制保持来源可追溯，讲稿的读图方向也要同步。

## 裁剪与分辨率

1. 先在完整页面上确定语义区域，包括必要的图例、样本/条件名、坐标轴、单位、缺失或失败标记、误差条、步骤编号和脚注。按实际图形选择清单，不要求每幅图都有这些元素。
2. 再测区域内的内容边界，保留少量余量。最长边 2200px 的预览中约 10px 可作为起点；换分辨率按比例换算。边界附近的浅色误差条、线条和标签需要看图确认。非白像素框、OCR 和边距数字都不能证明图已裁全，原图内部的有意义空白不必消除。
3. 预览坐标与成品清晰度分开。像素坐标必须记录所用 scale；需要多分辨率时，使用完整显示页面左上原点的归一化 `(x,y,w,h)` 区域。`--region` 按实际栅格尺寸向外取整；`--width-in` 与 `--ppi` 可按计划显示宽度确定输出分辨率，实际有效 PPI 由成品检查再次测量。
4. 保留原始矢量 PDF。若报告的导出链路已验证矢量嵌入，可使用矢量裁片；当前配套生成器只接受 PNG，不声称能保留 PPTX 内的矢量图。PNG 从原 PDF 按所需分辨率重裁，不放大小位图或重绘实验数据。增加像素只改善清晰度，不会增大最终页面中的文字。

图注可以与图形分开排版，但解释实验条件的必要内容必须随图交付。不要留下半段被截断的论文图注，也不要为了紧裁丢掉限定。

## 根据用途选版式

| 页面任务/结构 | 处理依据 |
|---|---|
| 单图与简短解释 | 使用 `figure`；需要调整位置时用 `figure_options`，让图注靠近实际图底边 |
| 宽表、宽机制图 | 优先 `placement: wide`，把解释移到下方；判断最细标签是否够大 |
| 多组可独立阅读的结果总览 | 可用 `figure-grid`，各组结论跟随对应裁片；数量由内容决定 |
| 精读刻度、误差条或异常点 | 优先拆页或设置细节放大区，每页保留比较条件与共享信息 |
| 用户明确固定页数 | 在固定预算内调整页面分工或版式；仍无法读清时说明具体冲突，不默默缩小或删除证据 |

已有页数本身不是用户的硬约束。没有固定页数时，按讲述问题和时长决定是否拆页，并同步页序、讲稿、转场及时间预算。极端长宽比是触发检查的线索，不是自动拆图或改页数的规则。

`figure-grid` 提供 2–4 张裁片、2–3 列、最多两行的常用容量，不把此容量当作复合图的结构上限。更多或有依赖关系的面板应拆页或在报告副本扩展版式。卡片数、面板数和指标名都不应成为生成器中的论文专用分支。

## 三项独立验证

- **完整性**：对照全文页和 `figure.required_elements` 查看裁片。记录父图、子图、共享解释及遗漏判断；sidecar 的 `visually_reviewed` 是人工检查记录，不能由边距或哈希检查自动置为 true。
- **素材与几何**：`report.py` 校验全部声明裁图的 PNG/sidecar/来源哈希、坐标和尺寸，再逐页核对图片关系与素材哈希、纵横比及额外 PPT 裁剪。`render` 使用 bundled Poppler 重放声明区域并比对实际像素；`check` 传入 `--pdftoppm` 时也执行此检查。只修改 `crop` 不会更新 PNG；每次重裁须同步内容包与 sidecar。渲染器版本变化导致像素不同也需要重新生成和审阅，不能自动接受不一致。
- **最终可读性**：查看全部拼图以及密集图的完整页面渲染，按目标显示尺寸检查必要的最小标签和细线。`check.json` 报告每张图的实际英寸尺寸、有效 PPI 和白色外边距；可记录 `label_height_px` 并设定本报告的 `meta.figure_quality` 阈值产生诊断。它是字形高度估计，不是字体字号。没有测量时不宣称可读性通过；高 PPI 和正确比例也不替代视觉检查。

质量阈值随投影、屏幕阅读或打印用途选择，不预置适用于所有论文的硬门槛。交付记录分别写清结构检查结果、裁剪完整性和可读性结论；任何未解决的诊断要注明对使用的影响。
