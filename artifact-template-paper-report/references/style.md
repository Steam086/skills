# Paper Report 视觉规范

来源为公开清理后的 8 页 `assets/reference.pptx`，只包含合成示例内容，已用 bundled LibreOffice 重新渲染并查看全部页面。`scripts/build.cjs` 提供几何和基础版式。模板不限制新论文页数与章节。

标题约 30 个英文字符是易用目标，不是硬限制。长论文名放封面副标题。实际是否单行由渲染判断。若系统没有 Arial，在 `meta.font_face` 中指定已安装的无衬线字体，并重新完成逐页视觉检查；不要假定不同机器的字体替换具有相同几何。

- `cover`：顶部青色细条、左侧简称与副标题、作者/报告人和时长；右侧有明确机制步骤时才放概览。
- `section`：左色条、章节名、主题与一句转场，按内容需要使用。
- `bullets`：平铺解释或目录，页面不承载完整讲稿。
- `comparison`：2–3 个并列块，明确机制和代价。
- `figure`：一张大原图，右侧最多 3 个解释块；caption 交代条件。
- `two-figures`：并列图与各自说明，不混淆两组条件。
- `figure-grid`：按语义图组排列 2–4 张裁片，说明跟随对应图底边；密集细节优先拆页，不用网格容量代替可读性判断。
- `table`：原生表格，最多 6 行数据、5 列；复杂表按内容拆分或扩展。
- `flow`：2–5 个原生步骤和连接线；仅用于确实顺序的机制，不歪曲并行/分支依赖。

参考页：1 封面；2 章节；3 要点；4 比较；5 单图；6 双图；7 表格；8 流程。

原图按比例 contain，不裁轴/图例。研究与算例写明证据性质。参考模板中的文字、数字和合成图仅用于展示版式，不是论文证据。

单图的短图上移、宽图通栏可用 `figure_options` 配置，不按具体图号或 slide ID 写布局特例。裁剪边界、矢量来源、共享标签与显示尺寸的判断见 [配图处理](figures.md)。
